Help and answers

Before you connect.

Straight answers about the planned sticker check and what stika can do today.

Is stika working now?

The current app is a preview. TikTok sign-in, export processing, and WhatsApp sticker-pack transfer are not enabled.

What information would stika request?

The planned TikTok permission is a one-time direct-message export. It is read-only and intended only to check for a separate original sticker file.

Does stika send or reply to messages?

No. Message sending is not part of the planned feature.

Will TikTok include the exact sticker?

That is not guaranteed. TikTok’s published export format does not promise separate sticker assets. stika will report when it cannot confirm an original file and will not recreate it from a screenshot.

Can I add a sticker to WhatsApp today?

No. WhatsApp handoff is still being built. It will depend on the original file meeting WhatsApp’s sticker-pack requirements and on the user confirming the import.

Which TikTok accounts can use the export?

TikTok currently describes Data Portability API coverage for users in the European Economic Area and the United Kingdom. People outside those regions may not be able to use this path.

How is export data handled?

The current app does not request an export. The development server is designed to inspect a future export temporarily in memory. See the Privacy Policy for details.

How can I ask a privacy question?

Email support@studenthubmarketing.co.za. Please do not include passwords or one-time security codes.
