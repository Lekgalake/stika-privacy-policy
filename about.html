The planned flow

Four clear steps. The user stays in control.

stika will use TikTok’s own sign-in and permission screen. The app will not send or reply to messages, and it will not reconstruct a sticker from a screenshot.

01

Review the request

See that stika is asking for one direct-message export, and why it needs it.

02

Choose TikTok

Continue to TikTok’s hosted sign-in and approve or cancel the request there.

03

Check the export

Look for a separate image or video file. A file in an export does not by itself prove it is the exact sticker.

04

Show the result

Report clearly whether a suitable original asset was found. WhatsApp transfer will only be offered after pack support is ready.

Current availability

Still in setup

The current app build previews the consent flow. TikTok sign-in and export are not enabled, and adding a sticker pack to WhatsApp is not available yet. We will update this page before those features are turned on.

Regional access

TikTok sets the boundary

TikTok currently describes Data Portability API coverage for users in the European Economic Area and the United Kingdom. People outside those regions may not be able to use this export path. Availability depends on TikTok and may change.

What to expect

Honest answers before you connect.

Will stika read my messages?

The proposed request is a one-time export of direct-message data. The current app does not request or process a TikTok export. If enabled, the policy explains the temporary file check and data handling.

Does the export guarantee the sticker?

No. TikTok’s documented fields do not promise a separate sticker asset. stika must report that honestly and will not substitute a screenshot or a recreated copy.

Will stika send messages?

No. The planned flow is read-only. stika will not send or reply to TikTok messages.

Can I transfer one sticker today?

Not yet. TikTok permissions and WhatsApp sticker-pack support are still in development. The current build is a preview, not a working transfer service.
